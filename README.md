# Plum Digital Skincare Companion 💜

> Reimagining skincare for the next generation — smart, aesthetic, and deeply personalized.

## 🧠 Project Context

This project is a **capstone submission for Product Matter 5.0**, conducted by **E-Cell, IIT Guwahati** — a national-level product management challenge.  
The challenge tasked us with conceptualizing a **digital-first, mobile-native skincare experience** for a traditional brand losing touch with the Gen Z demographic (18–25).  
It focuses on **building trust, personalization, and engagement** through tech-integrated, AI-powered solutions — all while preserving the credibility and core values of the legacy skincare brand.

---

## 🔍 Overview

A lightweight, AI-powered, mobile-first mini-app built for skincare brands like **Plum** to re-engage Gen Z audiences with an interactive skincare journey.

Built using tools like **Lovable**, **Replit**, and **Bolt**, the product delivers:
- ✨ Personalized skin analysis (via quiz, environment, and camera)
- 🔁 Smart routine building using brand’s existing catalog
- 📲 Modular deployment (QR-triggered from packaging, website embed, app integration)

## 📈 Goals & Success Metrics

**🎯 Goals:**
- Increase Gen Z engagement by 30%
- Boost quiz-to-product conversion rate
- Reduce product discovery drop-off

**📊 Metrics:**
- Daily Active Users (DAU) / Monthly Active Users (MAU)
- Routine creation rate
- Click-through rate to product pages
- Repeat visits and purchases
